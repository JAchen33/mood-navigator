# 🧭 心情小導航 - 轉念 SEL 情緒方向盤 (Mood Navigator)

轉一轉，找到照顧自己的方法！專為兒童與成人設計的 SEL（社會情緒學習，Social Emotional Learning）互動式情緒自我覺察與轉念引導工具。

🌐 **線上使用網址**：[https://jachen33.github.io/mood-navigator/](https://jachen33.github.io/mood-navigator/)

---

## 🌟 核心特色

- **🎨 手繪水彩風格介面**：溫暖親切的手繪線條與紙張質感，降低情緒防備心。
- **🎡 五大情緒方向盤**：
  - 🔴 **生氣**（紅色火山怪獸）：釋放衝動與怒氣
  - 🟡 **希望**（黃色星星狐狸）：凝聚期待與行動力
  - 🟢 **平靜**（綠色水中小熊）：穩定身心與專注呼吸
  - 🔵 **傷心**（藍色雨滴小雲）：承接脆弱與悲傷釋放
  - 🟣 **擔心**（紫色問號小兔）：釐清焦慮與辨認事實
- **👧 雙模式切換**：
  - **小學生模式**：具體、童趣、易於操作的引導語彙。
  - **大人模式**：具備深度覺察、客觀理性與認知重構的成人引導。
- **🗂️ 三大專屬療癒行動卡片**：
  1. 🍃 **身體覺察與放鬆**：正念呼吸、感官接地練習。
  2. 🎨 **藝術表達**：塗鴉、具象化情緒、媒材創作釋放。
  3. 💡 **轉念與行動**：認知重構、尋求支持與可落地的第一步。
- **⚡ 雙引擎驅動設計**：
  - **開箱即用**：內建豐富的本地引導庫，完全不需任何設定即可順暢運作。
  - **AI 深度解析**：支援選填 Google Gemini API Key（安全存放於個人瀏覽器 LocalStorage），即可即時生成針對個人具體事件的客製化深度建議。
